# 图标

仓库根目录的 `app-icon.png` 是 1024×1024 的源图，本目录下的所有尺寸都由它生成：

```bash
npm run tauri icon app-icon.png
```

- `icon.png`（512）用于窗口图标与安装包
- `128x128.png` 被 `src/components/Sidebar.tsx` 直接引用，所以应用内的侧边栏、任务栏、
  安装包里看到的永远是同一张图
- `ios/` 与 `android/` 是移动端尺寸，桌面构建用不到

改 logo 时只改根目录那一张，然后重跑上面的命令。**不要单独替换某一个尺寸**——
三个平台会各自显示不同版本的图标，而且没人会主动报这件事。
